### 阶段 G：解析服务改为纯标准库实现并更名 doremy（2026-10-25）

- 删除 FastAPI 版 `app.py`、`requirements.txt`、`install-termux.sh`、`test_resolver.py`。原因：Android 的 pip 只接受 `android_arm64` 平台轮子，`pydantic-core` 需要 Rust、`lxml`/`aiohttp` 需要 C 工具链，落到源码编译必然失败（`maturin: Rust not found`），安装脚本在手机上没有可用路径。
- 新增 `server.py`：标准库 `http.server` + yt-dlp（单文件 411 行），接口与旧版逐字段一致——`GET /health`、`POST /api/resolve`、`GET /api/videos/{id}`（含 Range 与 HEAD）、`DELETE /api/videos/{id}`，CORS 全开。
- 新增 `install-android.sh`：Termux 一键安装 `python + ffmpeg + curl` 与 `yt-dlp`，装到 `~/.doremy-video-resolver`，写入 `doremy-video-start/status/stop` 三个命令并自启自检。
- 命名统一：`momo-video-*` → `doremy-video-*`，`~/.momo-video-resolver` → `~/.doremy-video-resolver`，`~/.momo-video-cache` → `~/.doremy-video-cache`，服务标识 `momo-video-resolver` → `doremy-video-resolver`。
- 格式选择优先 H.264（`vcodec^=avc1`）：B 站 `bestvideo` 默认给 AV1，部分机型/WebView 硬解不了会黑屏；代价是同画质体积约大 60%。
- SSRF 校验放行 `198.18.0.0/15`：手机代理 Fake-IP 模式的假地址实际指向公网，旧版按 `is_global` 判定会把整段拒绝，导致所有链接无法解析；内网/回环仍拒绝。
- 新增 `test_server.py`（格式选择与 URL 守卫回归测试），CI 改为编译 `server.py` + 运行新测试，不再安装 `requirements.txt`。
- 「一起看 → 视频解析与本地缓存」与「运行诊断」里的部署命令同步改为 `install-android.sh`；解析策略下拉移除 `parse-video-py`，仅保留「自动 / 仅 yt-dlp」。
- 验证状态：网页端改动通过 `npx tsc --noEmit` 与 `next build`（GitHub Actions）；Termux 一键脚本在 Android 16 真机上执行成功，B 站 720p 实测可解析并合并出 H.264+AAC 的 mp4；抖音/快手走 yt-dlp，未逐一实测。

## 5. 同步到另一个仓库前的注意事项

1. **不要用整个开发仓库直接覆盖目标仓库。** 当前差异横跨网页、Android 原生、Supabase、部署工作流、可选服务和文档。
2. 先再次读取目标仓库最新 `main`，因为它可能在本次审计之后继续前进；重新生成差异清单。
3. 按模块同步并逐个检查配置/环境变量/Secrets/数据库 SQL/Edge Functions；只复制网页代码不等于后端能力已部署。
4. `android-shell/` 下 Kotlin、Manifest、资源或原生桥变化需要重新构建 APK；只部署网页不能更新已安装 APK 的原生部分。
5. 对被撤销或替换的实验保持谨慎：历史上曾试验的自定义全屏/弹幕、重复角色行为弹窗、关系纪念品子系统、照片墙旧身份参考拼图等，不应因历史提交存在就重新当作现行功能。
6. 生产构建检查已重新开启 TypeScript 检查；应检查 GitHub Actions 的最新结果，不以本地提交成功代替构建成功。
7. 「代码存在」「工作流通过」「云端已部署」「Android 真机验证通过」是四种不同状态，必须分别记录。

## 6. 验证状态的表述标准

- **代码已实现**：在当前源码中能找到对应入口与调用链。
- **自动检查通过**：对应 GitHub Actions/测试脚本的运行结果为 success。
- **部署已验证**：确认所需 Worker、Supabase Function、数据库迁移或站点已部署到目标环境。
- **模拟/真机通过**：记录设备、系统版本、操作步骤和结果。
- **待验证/受平台限制**：没有实际证据时必须如实标注，不得写成「已全面可用」。
