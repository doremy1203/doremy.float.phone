# 角色陪伴专注 · UI 精简与美化方案

> 目标：砍废话文案、收敛重复入口、视觉降噪 —— **不改变功能布局**（四主栏 + 6 分组页 + 背书分组保持原样），功能一项不删。
> 分析基线：custom-apps/focus-companion v1.9.4+M2a（PR #86 分支）。

## 1. 诊断数据（量化）

| 指标 | 数值 | 问题 |
|---|---|---|
| `tiny`/`sub` 说明文字块 | **816 块 ≈ 5 万字符** | 大量「机制解释/为什么这么设计」混在操作页里 |
| help（能力边界）视图 | **12.8 万纯文字字符，全应用最大** | 版本更新记录（19 处 v1.x 长文）、机制原理全部堆在这一个页 |
| album 入口 | **8 处** | 同一页 8 个入口 |
| appt / help / prompts 入口 | **各 5 处** | 功能入口与教学入口混排 |
| me（设置页） | 19.7KB 源码 | 设置项与长说明交织 |

## 2. 设计原则（依据 + 对应改法）

| 规范 | 依据 | 落到本 app |
|---|---|---|
| 渐进披露：默认只给现在需要的，其余降级到二级页 | [NN/g Progressive Disclosure](https://www.nngroup.com/articles/progressive-disclosure) | 操作页只留「一句话说明」；机制原理/版本记录/边界说明全部进「帮助中心」页 |
| 文案短而有用：先短，更要达意；同一件事全文用同一个词 | [NN/g UX Writing Study Guide](https://www.nngroup.com/articles/ux-writing-study-guide) | 三级文案规范（§3）；统一术语表（"催促/提醒/查岗"不再混用） |
| 间距走 4dp 基网格，token 化 | [M3 Spacing](https://m3.material.io/styles/spacing) | CSS 变量 `--sp-1..4`，替换散落的内联 mt6/mt8/mt10 |
| 色彩用语义角色而非散落色值 | [M3 Color Roles](https://m3.material.io/styles/color/roles) | 映射现有 `--bg/--ink/--ac` 到 `--surface/--on-surface/--primary` 等角色 |
| 标题更重、层级更明显（编辑感排版） | [M3 Expressive](https://m3.material.io/blog/material-3-expressive) | 卡片标题加重、tiny 统一降为弱化灰，减少加粗滥用 |

## 3. 三级文案规范（写进帮助中心页脚，后续开发照此执行）

| 级别 | 用在哪 | 上限 | 例子 |
|---|---|---|---|
| **L0 操作标签** | 按钮/chip/标签 | ≤6 字 | 「现在开始」「再赖会儿」 |
| **L1 一句话说明** | 控件下方/空状态 | ≤30 字，只说"这是什么/点了会怎样" | 「到点前 TA 来催你，3 次没开始就开罚」 |
| **L2 机制与边界** | 帮助中心页 | 不限 | 「催促怎么排程、为什么页面关了会补判」等 |

**删改规则**（批量执行）：
1. 操作页里解释"为什么/怎么实现的/改了什么"的文字 → 移入帮助中心，原位删除或压成 L1。
2. 同一信息在一页出现两次的，保留控件旁那条。
3. 版本更新记录（19 段）→ 全部收进帮助中心「更新记录」tab（可折叠），主界面清零。
4. 设置项的长解释 → 控件保留 + L1 短句 + 「详情」链接跳帮助中心对应锚点。
5. 语气规范：给 TA 的台词类文字不动（那是产品特色）；只砍"作者对用户解释"的部分。

## 4. 帮助中心页（新，单开一页功能使用说明）

- 入口：我的 → 「📖 帮助与说明」卡片（全 app 唯一帮助入口，收敛现有 5 处 gotoView help）
- 结构（页顶 tab 切换，复用现有 hub 模式）：
  1. **快速上手**：第一次用看什么（10 条以内，每条一句话）
  2. **机制说明**：催促与失约 / 壁纸与生图闸门 / 惩罚与豁免 / 系统闹钟兜底 / 现实桥只读 —— 各一段
  3. **更新记录**：现有 19 段版本说明原样搬入（折叠列表）
  4. **能力边界与隐私**：现 help 页保留部分
- 从各操作页删除的 L2 文字逐条登记到对应 tab，保证"删掉的不丢"

## 5. 入口收敛清单（只减入口，不动导航结构）

| 目标页 | 现状 | 收敛后 | 处置 |
|---|---|---|---|
| album（壁纸库） | 8 | 1（内容库 tab）+ 图片点击直达 | 其余改为"查看全部"单按钮或删除 |
| appt（预约） | 5 | 2（计划与邀请 hub + 到点弹层按钮） | 首页卡片点击即入 hub，不重复铺按钮 |
| help | 5 | 1（我的 → 帮助与说明） | 其余改为链接文字「什么是 XX？」进帮助锚点 |
| prompts（提示词设置） | 5 | 1（我的 → 提示词） | 其余入口删除 |
| bottle / periodrep / goals / coin / todos（各 3-4） | 3-4 | 所属 hub tab 内 1 个 | 重复的删，保留 hub 顶 tab |

原则：**同屏同目标只留一个可点入口**；功能按钮（如"现在开始"）不算入口，保留。

## 6. 视觉美化（Batch A 为 CSS-only，零布局风险）

1. **间距 token 化**：`:root` 增加 `--sp-1:4px --sp-2:8px --sp-3:12px --sp-4:16px`；现有 `.mt6/.mt8/.mt10/.mt12` 类改映射到 token（类名不变，改定义 —— 布局零风险）。
2. **字号/字重阶梯**：卡片标题 `h3` 提到 16px/700；`tiny` 统一 11.5px/`--ink3` 且**去掉部分加粗**；正文 14px 不动 —— 视觉焦点上移。
3. **色彩语义角色**：`--surface/--surface-2/--on-surface/--on-surface-2/--primary/--primary-soft` 映射现有变量；卡片/输入框/chip 只引用角色色，为暗色主题和宿主主题跟随铺路。
4. **卡片统一**：统一圆角 `--r:15px`、阴影一套 `--sh`、卡片间距 `--sp-3`；去掉零散的 `style="..."` 内联阴影/圆角（grep 逐个收编）。
5. **chip/btn 规范**：选中态统一 `--primary-soft` 底 + `--primary` 字；按钮高度统一 40px（触摸目标 ≥44dp 参考）。
6. **首页降噪**：保留「现在能做的那件事」为唯一大卡；次级卡片折叠为一行摘要 + 展开。

## 7. 分批实施（保证"不搞乱"）

| 批次 | 内容 | 风险 | 验收 |
|---|---|---|---|
| **A 视觉** | §6 全部（CSS-only，类名/结构不变） | 极低 | 四主栏/6 hub 截图对比，布局无位移 |
| **B 文案** | §3 规则批量执行 + 术语统一 | 低 | 每页只剩 L0/L1；功能文案（TA 台词）逐字未动 |
| **C 帮助中心 + 入口收敛** | 新页 + §5 清单 + L2 内容搬迁移册 | 中 | 删除的 L2 全部在帮助中心可找到；入口计数达标 |
| **D 回访** | 你真机过一遍，挑出"还啰嗦"的点 | — | 二轮微调 |

每批一个提交，可单独 revert；source.ts 由生成脚本重建，`node --check` + lint + build 逐批跑。
